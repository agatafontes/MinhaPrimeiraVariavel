# Minha Primeira Variável

Este programa foi criado para testarmos a criação de variáveis.

## O que é uma variável?

Uma variável é uma função/objeto.

## O que faz o Console.Write?

O Console.Write manda o programa escrever na mesma linha.

## Qual é a diferença entre Console.Write e Console.WriteLine?

A diferença é que o write escreve na mesma linha,  e writeLine escreve e quebra uma linha.
